# הזמנת חולצות צוותיות

אתר פשוט לאיסוף הזמנות לחולצות: בוחרים פרינט, סוג חולצה ומידה, משלמים בפייבוקס ושולחים.
האתר רץ ב-GitHub Pages, וההזמנות נשמרות בגיליון גוגל דרך Google Apps Script.

## מה יש כאן

| קובץ | תפקיד |
| --- | --- |
| `index.html` | האתר כולו (עיצוב, טופס והלוגיקה שלו) |
| `config.js` | הכתובת של הסקריפט שכותב לגיליון |
| `img/` | תמונות החולצות והלוגו |
| `apps-script/Code.gs` | הסקריפט שמדביקים בגיליון גוגל |

## חיבור לגיליון גוגל (פעם אחת)

1. פותחים גיליון גוגל חדש, ואז תוספים ← Apps Script.
2. מוחקים את הקוד שמופיע ומדביקים את התוכן של `apps-script/Code.gs`.
3. פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט. הפעלה בתור: אני. גישה: כל אחד. מאשרים את ההרשאות.
4. מעתיקים את כתובת אפליקציית האינטרנט (מסתיימת ב-`/exec`).
5. מדביקים אותה ב-`config.js` בין הגרשיים ושומרים:

   ```js
   window.SHIRTS_API_URL = 'https://script.google.com/macros/s/XXXX/exec';
   ```

כל עוד `config.js` ריק, האתר מציג הודעת "בהקמה" ולא שולח הזמנות.

אחרי כל שינוי ב-`Code.gs` צריך לפרוס גרסה חדשה: פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה. הכתובת לא משתנה.

## הלשוניות בגיליון

הלשוניות נוצרות לבד בכניסה הראשונה לאתר אחרי החיבור.

- **הזמנות**: שורה לכל חולצה, עם פרטי המזמין, הפרינט, הסוג, המידה, הכמות והמחיר.
- **סיכום**: כמויות לפי פרינט, סוג ומידה, וסכום לתשלום לכל הזמנה (להשוואה מול פייבוקס).
- **פרינטים**: שם, האם מטושטש, הערה, פעיל, ואיזה צד של החולצה מוצג בכרטיס.
- **תמונות**: תמונה מלפנים ומאחור לכל צירוף של פרינט וסוג חולצה.
- **חולצות**: סוג, מחיר ומידות (מופרדות בפסיקים).
- **הגדרות**: כותרת, טקסט פתיחה, קישור פייבוקס, ופתיחה או סגירה של ההזמנות.

שינוי בגיליון מופיע באתר ברענון הבא. המחיר שנרשם בהזמנה הוא תמיד המחיר שבגיליון.

## הוספת פרינט חדש

1. מעלים את התמונות לתיקיית `img/` (למשל `new-oversize-front.jpg`).
2. ב-`index.html` מוסיפים שורה לכל תמונה ברשימת `IMAGES`.
3. בגיליון מוסיפים שורה בלשונית "פרינטים" ושורות מתאימות בלשונית "תמונות".
